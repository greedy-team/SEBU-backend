# SEBU 학과 자료 크롤링

- 작성일: 2026-10-06
- 작성한 Skill: `crawling`

작업 전에 [크롤링·오타·연구분야 검수 기준](references/2026-10-06-crawling.md)을 읽는다.

요청한 URL과 반영 범위를 기준으로 기존 크롤러를 실행하고, 공식 원문과 검수 CSV 및 최종 저장값을 대조한다. 연구분야 분리·카테고리 연결과 배포는 요청에 포함된 범위에서 수행한다.

원문 연구소개와 검색용 연구분야 이름을 분리하여 관리한다. 오타는 근거 없이 자동 교정하지 않고 원문·수정값·근거를 남긴다. 기존 데이터와 수동 관리값을 보존하며, 검증 결과와 남은 불확실성을 핵심만 보고한다.
