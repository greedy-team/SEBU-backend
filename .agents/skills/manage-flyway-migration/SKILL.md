# Flyway 마이그레이션 관리

- 작성일: 2026-08-17
- 작성한 Skill: `manage-flyway-migration`

마이그레이션을 변경하기 전에 [Flyway 변경 기준](references/2026-08-17-manage-flyway-migration.md)을 읽는다.

## 필수 규칙

- 기존 마이그레이션과 관련 엔티티를 확인한다.
- 적용됐을 수 있는 버전 파일은 수정하지 않고 다음 버전의 새 파일을 만든다.
- 운영 MySQL 문법을 기준으로 작성하고 H2 통과만으로 호환성을 판단하지 않는다.
- SQL의 타입, 길이, NULL, 기본값, 제약조건과 JPA 매핑을 일치시킨다.
- 데이터 손실 가능성이 있는 변경은 사용자 승인 없이 수행하지 않는다.
- 기존 데이터가 있는 변경은 단계적으로 적용한다.
- 운영 DB에 직접 실행하거나 비밀값을 파일에 기록하지 않는다.

## 완료 조건

- 빈 DB의 전체 마이그레이션과 기존 DB의 업그레이드 경로를 검증한다.
- 관련 테스트와 Hibernate 스키마 검증 결과를 확인한다.
- MySQL 호환성, 잠금, 데이터 손실 위험을 결과에 알린다.
